# Investment Risk Memo ジェネレーター

**投資前に読みたい論点を、チェックを入れるだけで1枚のメモにまとめるツールです。**

![メモの完成画面](./screenshot.png)

▶ デモ：https://myn0306.github.io/risk-memo-generator/

## 何が楽になるか

中小企業の買収や出資を検討するとき、「どこにリスクがあるか」「何の書類を見ればいいか」「売り手に何を聞けばいいか」を毎回ゼロから整理するのは手間がかかります。

このツールでは、会社の基本情報と当てはまる論点にチェックを入れるだけで、次の内容が1枚にまとまります。

- 総合所見（慎重／条件付／前向き）
- 重点リスクと、その対応策
- 取得価格以外にかかりうる費用（未払い残業代、設備更新、簿外債務など）
- 確認すべき書類の一覧
- 売り手に聞くこと
- 保険で移せるリスクと、その注意点（D&O、表明保証保険、EPLIなど）

できたメモは、PDFで保存したり、テキストでコピーして共有したりできます。

## 作った理由

後継者不在の中小企業には、許認可・官公庁との取引・資格者・地域の信用など、価格に表れていない価値を持つ会社が多くあります。一方で、小さな案件ほど調査に時間とお金をかけられず、リスクの見落としが起きやすくなります。

「買収後の面倒ごとを引き受ける」仕組みをつくる構想の入口として、まず投資家が最初に読む1枚を誰でも作れるようにしました。

## 特徴

- 人・組織、顧客・取引、財務・税務、許認可・法務、設備・ITの5分野、17の論点
- 業種（建設・測量、医療・福祉など）に応じて確認書類を追加
- 株式取得と事業譲渡で注意点を切り替え
- サーバー不要。入力内容はブラウザの中だけに保存され、外部に送信されません

## 使い方

1. デモを開く（架空の会社のサンプルが入っています）
2. 会社情報を入力し、当てはまる論点にチェックを入れる
3. 右側のメモを確認し、「印刷・PDFで保存」または「テキストでコピー」

## 技術

HTML / CSS / JavaScript の1ファイル構成。ライブラリ不使用。GitHub Pagesで公開。

## 注意

このツールは投資前の論点整理のための参考資料を作るものです。法務・税務・保険の判断は、各分野の専門家の確認を受けてください。表示されるサンプルの会社はすべて架空です。
